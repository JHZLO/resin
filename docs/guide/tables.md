# Tables

A table is a name, an optional description, and its columns between braces.

```erd example file=orders.erd
table orders "Customer orders" {
  id         bigint    pk
  placed_at  datetime
}
```

## Names and descriptions

Table names are unique within a document, external tables included. The description, in double quotes, is for people: it shows next to the name in the diagram and in the side panel, and resin reads nothing into it.

A short table can sit on one line:

```erd
table tags { id bigint pk }
```

## Statements end at the line

A newline ends a statement, so every column sits on a line of its own. Inside parentheses newlines are ignored, which lets a long `enum(...)` wrap:

```erd example file=payments.erd
table payments {
  id      bigint   pk
  method  varchar  enum(
    CARD,
    BANK_TRANSFER,
  )
}
```

## Comments

`%%` starts a comment that runs to the end of the line. See [Names and comments](names.md).

## Other kinds of table

- [External tables](external-tables.md) live outside the document: in another service, or another database.
- [Audit tables](audit.md) are generated by `audit envers`.
